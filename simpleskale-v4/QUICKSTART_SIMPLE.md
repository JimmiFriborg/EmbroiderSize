# SimpleSkale 4.0 - Ultra-Simple Quick Start

**No technical knowledge needed!**

---

## 🚀 3 Simple Steps

### Step 1: Install (One Time Only)

1. **Right-click** `install.bat`
2. **Select** "Run as Administrator"
3. **Wait** 20-40 minutes
4. **Restart** your computer

---

### Step 2: Run SimpleSkale (Every Time)

**Choose ONE of these methods:**

**Method A: GUI (Easiest)**
- Double-click `SimpleSkale.vbs`
- Follow the friendly messages

**Method B: Console**
- Double-click `run.bat`
- A window will open

---

### Step 3: Use SimpleSkale

**That's it!** The SimpleSkale window will open automatically.

---

## 🎯 That's All!

**No troubleshooting needed!**
- Both `install.bat` and `run.bat` fix problems automatically
- You don't need to run any fix scripts manually
- Just double-click and go!

---

## ❓ What If Something Goes Wrong?

**It won't!** But if it does:

1. **Try running again** - Most issues fix themselves on the second try
2. **Check you restarted** - After install.bat, you MUST restart your computer
3. **Update Node.js** - If still having issues, download latest from https://nodejs.org/

---

## 🔧 Behind the Scenes (You Don't Need to Know This)
